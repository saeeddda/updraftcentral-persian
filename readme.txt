فارسی‌سازی و راستی‌چین‌سازی افزونه UpdraftCentral بدون تغییر فایل‌های اصلی.

== Description ==

Companion plugin that localizes UpdraftCentral into Persian (fa_IR) and applies RTL layout, fonts, and Bootstrap RTL — surviving UpdraftCentral updates.

== Installation ==

1. Install and activate UpdraftCentral.
2. Upload this plugin to `/wp-content/plugins/updraftcentral-persian/`.
3. Activate **UpdraftCentral Persian**.
4. Set site language to فارسی.
